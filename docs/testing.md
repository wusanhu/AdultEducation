# 测试记录

本文记录当前版本的构建、接口、业务与前端验收结果。测试环境为本地单机：MySQL 8.0.46（`127.0.0.1:3306`，root 空密码）、Redis 7、JDK 21、Node.js 20、Chromium（Playwright）。

## 1. 构建验证

| 项目 | 命令 | 结果 |
| --- | --- | --- |
| 后端编译 | `cd backend && mvn -q -DskipTests compile` | 通过 |
| 后端打包 | `cd backend && mvn -q -DskipTests package` | 通过，生成 `target/credit-platform.jar`（约 80 MB，含前端静态资源） |
| 管理后台 | `cd admin && npm run build` | 通过，输出到 `backend/src/main/resources/static/admin` |
| 移动端 H5 | `cd mobile && npm run build` | 通过，输出到 `backend/src/main/resources/static/m` |

前端均执行 TypeScript 类型检查后完成 Vite 构建，无类型错误。

## 2. 自动建库建表

- 首次启动时由 JDBC 参数 `createDatabaseIfNotExist=true` 自动创建 `adult_edu` 库。
- `spring.sql.init` 依次执行 `db/schema.sql` 与 `db/data.sql`。
- `schema.sql` 使用 `CREATE TABLE IF NOT EXISTS`，共 26 张表；`data.sql` 使用 `INSERT IGNORE`，重复启动不会覆盖业务数据。
- 已验证空库启动可自动完成建库、建表、初始化菜单/角色/字典/参数与演示数据。

## 4. 业务链路验证

- **学习会话**：开始学习、30 秒心跳、暂停/恢复、断点续播、进度百分比回显均正常；重复打开同一课程返回 409 并提示先在原设备退出。
- **防作弊**：心跳中断、切屏阈值、禁止快进、随机弹窗超时等分支已通过接口与页面联调验证。
- **身份核验**：人脸模拟核验、短信验证码发送与提交均可完成，核验记录可在学员端查询。
- **学分**：课程完成后自动发放；管理端人工补录、领导复核、管理员终审、撤销均验证通过。
- **毕业**：资格校验、学员申请、教员 → 领导 → 管理员三级审批通过后生成证书。
- **电子证书**：证书编号 `JXJY-2026-1-000001`，PDF 可通过 `/uploads/certificate/2026/JXJY-2026-1-000001.pdf` 下载，文件头为 `%PDF-1.5`，1 页。
- **文件上传**：图片/视频类型按扩展名与文件头双重校验，伪造扩展名文件被拒绝。
- **登录安全**：连续失败锁定、Redis 单会话令牌、首次登录强制改密、操作/登录日志均验证通过。

## 5. 前端端到端验证

使用 Playwright + Chromium，管理后台按桌面视口、移动端按 iPhone 13 视口执行。

### 管理后台

- 覆盖 25 个路由：登录、首页、培训班、课程、题库、学习监控、核验记录、学分台账/审批、毕业审核/档案、总览与四类统计报表、组织/用户/角色/菜单/参数/字典、操作日志、登录日志、个人中心。
- 页面切换无控制台错误、无未捕获异常；报表路由切换会重新加载数据，不会残留上一张报表内容。
- 已验证项目/课程新建、编辑、删除、发布，用户新增/重置密码/导入模板下载，报表 Excel 导出等操作。
- 整体布局改为“顶部通栏 + 左侧导航 + 右侧内容”：顶栏固定品牌、折叠按钮、页面标题/面包屑与消息通知；侧栏位于顶栏下方并独立吸顶。
- 顶栏与侧栏统一使用 `#fafcff` 底色并移除相互之间的分隔线，形成连续的 L 型整体；右下工作区改为 `#ffffff` 白底容器（16px 圆角、浅边框），内部模块全部用 1px 细线勾勒边界并以留白分隔，工作台统计区改为一条四列栅格，列与列之间用竖线区隔。
- 全站采用平面化设计：管理端与移动端均全局禁用 `box-shadow`（含 Ant Design Vue / Vant 组件的默认浮层阴影），层级改用 1px 描边与底色对比表达；下拉、弹窗、提示、抽屉、底部操作栏、Tabbar 等补充边框保证边界可辨，并保留 `:focus-visible` 描边以维持键盘可访问性。
- Playwright 遍历管理端工作台、课程列表、修改密码弹窗与移动端登录、首页、学分页的所有 DOM 节点，计算样式 `box-shadow` 均为 `none`；布局、下钻导航、模块卡片与移动端底部导航显示正常。
- 管理端引入代码级皮肤机制：`src/theme/skins/line.ts` 同时定义 Ant Design Vue `ThemeConfig` 令牌与控制台 CSS 变量，`src/theme/index.ts` 按 `window.__ADMIN_SKIN__` → `VITE_ADMIN_SKIN` → 默认皮肤的顺序解析并写入根节点；界面不提供任何皮肤切换入口，仅可通过代码、构建变量或部署时注入的全局变量控制。
- 左侧导航采用两级下钻：默认仅展示一级入口（工作台、培训管理、学分管理、毕业审核、统计报表、系统管理），点击模块后以左右滑动动画切换到二级菜单并替换当前面板，左上角返回可回到一级；进入详情页或刷新时会自动定位并展开所属模块。
- 一级入口显示模块图标、名称与功能摘要，二级菜单显示浅蓝胶囊选中态与圆点；侧栏支持 240px / 76px 折叠并记忆状态，折叠后保留图标与悬浮提示。
- 侧栏底部快捷操作逐行展示，人员信息改为横向排列：头像在左，姓名与“角色 · 在线”在右侧上下两行；折叠后仅保留头像并居中。
- Playwright 验证：一级入口 6 个、二级菜单 6 项渲染正常；点击“培训管理”后动画切换并显示子菜单，点击“课程管理”跳转 `/course/list` 且选中态与面包屑同步；返回一级后当前模块仍有高亮；折叠宽度 76px、文字隐藏；工作区计算背景为 `rgb(255, 255, 255)`、模块边框为 `rgb(238, 242, 247)`、人员信息 `flex-direction: row`；无控制台异常（仅 favicon 404）。

### 管理端图表与环境变量（本轮优化）

- 管理端移除 `echarts`，工作台趋势图改用 `@antv/g2` 5.4.8 绘制：学习分钟为左侧 Y 轴的蓝色面积+折线，发放学分为右侧独立 Y 轴的绿色柱状，柱状标记最后绘制避免被面积遮挡；自定义图例与坐标轴标题，隐藏 G2 默认字段名标题。
- Playwright 在 1440×1000 视口验证：工作台图表渲染为单个 731×290 Canvas，左右坐标轴刻度正常，图例、柱状与折线均可见，无页面异常（仅浏览器请求 favicon 的 404）。
- 图表在窗口尺寸变化时调用 `chart.forceFit()` 重排，路由离开时 `chart.destroy()` 释放实例，切换页面不会残留 Canvas。
- `admin/`、`mobile/` 均新增 `.env`、`.env.development`、`.env.production`，统一管理标题、基础路径、接口/上传前缀、开发代理与端口；`vite.config.ts` 通过 `loadEnv(mode, ...)` 读取，`index.html` 使用 `%VITE_*%` 占位符，路由 history 使用 `import.meta.env.BASE_URL`。
- 已验证：`npm run dev` 读取开发配置并代理 `/api`、`/uploads` 到 `http://127.0.0.1:8080`；`npm run build` 读取生产配置，产物标题正确替换，静态资源路径分别为 `/admin/` 与 `/m/`。

### 移动端首页与视频进度控制（本轮优化）

- 首页重新设计：顶部显示年度学分概览，四个统计卡片（学习中/已完成/总学分/待审核）均支持点击跳转；功能入口改为图标宫格并增加按压反馈；继续学习卡片展示封面、培训班、进度百分比。
- 修复首页继续学习卡片跳转 `/study/undefined` 的问题：项目详情课程对象使用 `id` 字段，卡片已按 `id`（兼容 `courseId`）跳转。Playwright 验证入口、统计卡片、学分概览与课程卡片分别进入 `/projects`、`/credits`、`/study/2`，无控制台错误。
- 课程新增/编辑页新增“视频进度控制”开关（`allowSeek`，可拖动/不可拖动），保存后写入 `course.allow_seek`，管理端接口与移动端课程详情一致。
- 关闭进度控制（`allowSeek=0`）时：移动端隐藏原生播放器控件，使用自定义播放/暂停、时间与只读进度条；任意方向拖动均会回退到连续播放位置并提示“本课程不允许拖动进度”；页面顶部提示“进度已锁定，不可拖动”。
- 开启进度控制（`allowSeek=1`）时：恢复原生控件，可自由拖动；Playwright 验证拖动到 120s 后位置保持，锁定课程拖动后回退到 0s。
- 视频播放验证：`sample.mp4` 在 Chromium 中可正常播放并推进进度（10s → 11.2s），无解码错误。
- 修复底部导航“首页”切换失效：Vant `route` 模式在 `/` 嵌套子路由下会把“首页”始终判定为激活，导致从“我的/学分/培训班”点击“首页”无响应；现改为按 `route.path` 计算激活项并显式 `router.push`，四个 Tab 往返切换均正常。

## 6. 演示与限制

- 人脸核验、短信验证码默认使用本地模拟实现（`app.face.mock=true`、`app.sms.mock=true`），生产环境需接入真实服务并关闭模拟开关。
- 演示视频为占位 MP4，仅用于播放/进度/防作弊流程演示。
- 测试过程中产生的学习记录、学分与毕业证书仅存在于本地测试库，不影响全新环境的初始化数据。
